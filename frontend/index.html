Páginas de este sitio

Formulario

Autoevaluación (Employee)

Cada persona evalúa su propio nivel en las funciones, hard skills y soft skills de su perfil.

  • Selecciona tu nombre.
  • Responde una pregunta a la vez — cada nivel trae su descripción completa, no adivines.
  • Revisa el resumen antes de enviar.
Abrir formulario →
Formulario

Evaluación de Líder

El líder evalúa a cada colaborador de su equipo directo.

  • Selecciona tu nombre como líder.
  • Elige al colaborador a evaluar (solo aparecen tus reportes directos).
  • Responde con base en lo observado, no en el potencial.
Abrir formulario →
Formulario

Evaluación entre Pares

Un compañero cercano evalúa de forma completa, o un evaluador externo evalúa solo hard skills con estándar de industria.

  • Interno: compañero de tu misma área, evaluación completa.
  • Externo: proveedor/evaluador técnico, solo hard skills.

Qué significan las métricas

Promedio general: promedio de todas las skills evaluadas de una persona, combinando las 3 perspectivas (Employee, Leader, Peer).
Promedio por categoría (Función / Hard Skill / Soft Skill): el mismo cálculo pero separado por tipo de competencia — permite ver si el gap es técnico, funcional o de comportamiento.
Employee / Leader / Peer (por skill): el promedio de puntaje que dio cada tipo de evaluador para esa skill específica. Una diferencia grande entre ellos revela una brecha de percepción (ej. la persona se autoevalúa más alto que su líder).
Promedio del área (▲ / ▼): el promedio de esa misma skill entre los demás compañeros de la misma área — sirve como referencia de "dónde estoy parado frente a mi equipo", no como un objetivo absoluto.
Top gaps / Prioridades de desarrollo: las skills con el promedio más bajo — son las candidatas naturales para convertirse en compromisos de desarrollo en el Career Path.
Nota sobre esta PoC: los dashboards no se recalculan en tiempo real en cada clic — se generan con el script compute_dashboards.py, que debe correrse cada vez que se quiera refrescar los números (por ejemplo, al cerrar una ronda de evaluación). Esto es intencional: mantiene el sistema simple de operar para un equipo de RH sin soporte técnico permanente.
